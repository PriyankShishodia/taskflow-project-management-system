TaskFlow — Project & Task Management System
Managing projects across multiple team members can become difficult without a centralized system for tracking responsibilities, deadlines, and progress.
TaskFlow aims to solve this problem by providing a centralized platform where users can manage projects and tasks, access relevant information based on their roles, attach supporting files, and track important activities.

Why TaskFlow?
Centralized management: Keep project and task information organized in one place.
Secure access: Authenticate users and enforce role-based permissions.
Improved visibility: Use dashboard analytics to monitor project and task progress.
Accountability: Maintain audit logs of important activities.
Developer-friendly APIs: Explore and test API endpoints using Swagger documentation.
Reliable development workflow: Support automated tests and Docker-based environments.
Key Features
1. Authentication and Authorization
JWT-based authentication.
Protected endpoints for authenticated users.
Role-based access control (RBAC).
Permission checks for authorized operations.
Controlled access to project and task resources.
2. Project Management
Create and manage projects.
Organize work around individual projects.
Access project-related information.
Manage project operations according to user permissions.
Maintain a structured view of ongoing work.
3. Task Management
Create and manage tasks associated with projects.
Track task-related information and progress.
Organize work into manageable units.
Control task operations according to authorization rules.

Project and task statistics.
